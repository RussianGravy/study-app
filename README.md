# Social Study App
## About

This app stores flash cards for studying. <br>
[Try it here!](https://study-app-seven.vercel.app/landing)

- Authentication and storage are achieved through Firebase.
- Front end is made using React.

## Why I started this project

I wanted an app that could store digital flashcards. The
feature to view other users' flashcards also makes this application a great way to study collaboratively.

## What I learned
I learned how to utilize API's and the React framework to create a responsive web app.

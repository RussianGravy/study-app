# Social Study App

This app stores flash cards for studying. [Try it here!](https://study-app-seven.vercel.app/login)

- Authentication and storage are achieved through Firebase.
- Front end is made using React.

## Why I started this project

I wanted an app that could store digital flashcards. The innovative
feature to share flashcards with other users also makes this application a great way to study collaboratively.

## What I learned
I learned how to utilize API's and the React framework to create a responsive web app.
